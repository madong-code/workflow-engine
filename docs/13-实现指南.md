> 将引擎接入业务系统：服务实现、扩展点与第三方对接。

## 一、服务实现

引擎通过 `I*Service` 接口获取服务，业务系统需实现这些接口并注入 `EngineConfig::services`。

### 核心服务

| 接口 | 职责 |
|------|------|
| `IProcessDefineService` | 流程定义管理（CRUD、解析为模型） |
| `IProcessInstanceService` | 流程实例管理（创建、完成、变量） |
| `IProcessTaskService` | 任务管理（创建、完成、待办列表、协办） |
| `IProcessTaskActorService` | 任务参与者 |
| `IProcessInstanceHistoryService` | 实例历史 |
| `IProcessTaskHistoryService` | 任务历史 |
| `IProcessTaskActorHistoryService` | 任务参与者历史 |

### 可选服务

| 接口 | 职责 |
|------|------|
| `IProcessTypeService` | 流程分类 |
| `IProcessFormService` / `IProcessFormHistoryService` | 表单及版本历史 |
| `IProcessDesignService` / `IProcessDesignHistoryService` | 设计器模型及版本历史 |
| `IProcessDefineFavoriteService` | 流程收藏 |
| `IProcessCcInstanceService` | 抄送实例 |
| `IProcessSurrogateService` | 委托代理规则 |

> 可选服务未注入时相关功能不可用（引擎按需判空），核心服务必注入。

### 注入

```php
$engine = new Engine(new EngineConfig(
    services: [
        IProcessDefineService::class => \App\Service\ProcessDefineService::class,
    ],
));
```

> 内存服务示例见 `tests/fixture/memory/`，可作为实现参考。

## 二、扩展点

### 1. 自定义节点

实现 `clazz` 类（点号形式配置），方法签名 `($ctx, $args)`，结果写入 `var`：

```php
namespace App\Workflow;

use madong\workflow\context\ExecutionContext;

class AmountCalculateHandler
{
    public function calculate(ExecutionContext $ctx, mixed $args): mixed
    {
        return $ctx->getVariable('f_amount', 0);
    }
}
```

类不存在时引擎**安全降级**（直接转发，不中断流程）。

### 2. 节点拦截器

通过节点 `pre_interceptors`/`post_interceptors` 配置拦截器类，节点执行前后触发。

### 3. AOP 切面

实现 `Aspect` 接口，按 `JoinPoint` 织入逻辑：

```php
$engine = new Engine(new EngineConfig(aspects: [\App\Workflow\AuditAspect::class]));
```

### 4. 事件监听

实现 `ProcessEventListener`，订阅 `EventBus` 事件：

```php
$engine->getEventBus()->subscribe('task.start', new NotificationListener());
```

### 5. 模块

实现 `Module` 接口，带生命周期（register/boot/shutdown），依赖自动拓扑排序：

```php
$engine = new Engine(new EngineConfig(modules: [\App\Workflow\NotifyModule::class]));
```

### 6. 新节点类型

实现 `NodeParser` + `NodeModel` + `Handler`，注册到 `NodeParserRegistry`。

## 三、第三方设计器对接

实现 `DesignerParserInterface`，将第三方格式映射为引擎 snake_case 的 `LfModel`：

```php
interface DesignerParserInterface
{
    public function getName(): string;
    public function supports(array $data): bool;
    public function parse(array $data): LfModel;
}
```

注册：

```php
$engine->getDesignerRegistry()->register(new MyDesignerParser());
```

## 四、命名规范

- 流程定义 json、节点属性：**统一 snake_case**（`perform_type`、`instance_url`）
- 类名引用：**点号形式**（json 不允许 `\`），引擎自动转命名空间
- 表达式：`#变量` / `${变量}`
