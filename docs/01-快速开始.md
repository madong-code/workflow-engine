# 快速开始

> 📚 阅读顺序 **1/14** · 起点 · ▶ 下一节 [02-引擎API](02-引擎API.md) · [目录](README.md)

> 从零启动并运行一个请假流程的最小示例。

## 1. 安装

本包未发布到 Packagist，先在项目 `composer.json` 配置 VCS 仓库：

```json
{
    "repositories": [
        { "type": "vcs", "url": "https://gitee.com/motion-code/workflow-engine.git" }
        // GitHub 镜像备选：https://github.com/madong-code/workflow-engine.git
    ]
}
```

```bash
composer require madong/workflow:^3.0
```

要求：PHP 8.1+、Composer 2.x。

## 2. 创建引擎

```php
use madong\workflow\Engine;
use madong\workflow\config\EngineConfig;
use madong\workflow\interface\services\{
    IProcessDefineService,
    IProcessInstanceService,
    IProcessTaskService,
};

$engine = new Engine(new EngineConfig(
    services: [
        IProcessDefineService::class   => \App\Service\ProcessDefineService::class,
        IProcessInstanceService::class => \App\Service\ProcessInstanceService::class,
        IProcessTaskService::class     => \App\Service\ProcessTaskService::class,
    ],
    debug: true,
));
```

## 3. 发布流程定义

```php
$defineService = $engine->getService(IProcessDefineService::class);
$defineService->createProcessDefine([
    'id'      => 'leave_001',
    'name'    => 'wf-leave',
    'content' => $jsonContent, // 流程定义 json 字符串
]);
```

> 流程定义 json 格式见 [03-流程定义](03-流程定义.md)。

## 4. 启动流程

```php
$instance = $engine->startProcess('leave_001', 'user001', [
    'initiator' => 'user001',
    'manager'   => 'manager001',
    'f_day'     => 3,
]);
```

## 5. 查询待办任务

```php
$taskService = $engine->getService(IProcessTaskService::class);
$tasks = $taskService->getDoingTaskList($instance->getId(), '');
```

## 6. 完成任务

```php
$engine->completeTask($tasks[0]->getId(), 'user001', ['approved' => true]);
```

## 7. 驳回 / 跳转

```php
$engine->rejectToEnd($taskId, 'user001');     // 驳回到结束节点
$engine->rejectToFirst($taskId, 'user001');   // 驳回到首个任务
$engine->jumpTask($taskId, 'user001', 'apply'); // 跳转到节点
```

## 8. 运行测试

```bash
vendor/bin/phpunit --no-coverage
```
