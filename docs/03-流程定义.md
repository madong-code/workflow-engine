# 流程定义

> 📚 阅读顺序 **3/14** · ◀ 上一节 [02-引擎API](02-引擎API.md) · ▶ 下一节 [流程能力总览](04-流程能力总览.md) · [目录](README.md)

> 流程定义以 LogicFlow 设计器导出的 json 为基准，**统一使用 snake_case（下划线）字段命名**，不做 camelCase 兼容。

## 一、顶层结构

```json
{
  "name": "wf-leave",
  "display_name": "请假流程",
  "instance_url": "leaveForm",
  "nodes": [],
  "edges": []
}
```

| 字段 | 说明 |
|------|------|
| `name` | 流程定义名（唯一） |
| `display_name` | 显示名称 |
| `instance_url` | 表单/实例 URL |
| `nodes` | 节点列表 |
| `edges` | 边（迁移）列表 |

## 二、节点 (nodes)

```json
{
  "id": "approve",
  "type": "ingenious:task",
  "x": 100, "y": 200,
  "text": { "value": "部门审批" },
  "properties": { "...": "..." }
}
```

> 节点 `type` 是设计器字面量，**保留原始大小写**（如 `ingenious:wfSubProcess`）；仅节点 `properties` 内字段统一 snake_case。

| 节点类型 | 说明 |
|----------|------|
| `ingenious:start` | 开始节点 |
| `ingenious:end` | 结束节点 |
| `ingenious:task` | 任务节点 |
| `ingenious:decision` | 决策节点（按表达式走分支） |
| `ingenious:fork` | 并行分支 |
| `ingenious:join` | 合并节点 |
| `ingenious:custom` | 自定义节点（调用外部类） |
| `ingenious:wfSubProcess` | 子流程节点 |

### 流程级属性（顶层，与 nodes/edges 平级）

| 属性 | 说明 |
|------|------|
| `name` / `display_name` / `instance_url` | 见「顶层结构」 |
| `pre_interceptors` / `post_interceptors` | 流程级前置/后置拦截器类（点号形式，字符串） |

### 各节点通用属性

| 属性 | 说明 |
|------|------|
| `pre_interceptors` / `post_interceptors` | 节点级前置/后置拦截器类（点号形式，字符串） |
| `ext` | 任意扩展数据（引擎透传，不解析） |

> start / end / fork / join 无额外业务属性。

### 决策节点属性

| 属性 | 说明 |
|------|------|
| `expr` | 决策表达式（通常不配，改配在出边 `properties.expr`） |
| `handle_class` | 自定义决策处理类（点号形式，返回目标节点名） |

### 任务节点属性

| 属性 | 说明 |
|------|------|
| `form` | 任务处理表单地址 |
| `assignee` | 处理人（支持 `${var}`、`node.var`） |
| `assignee_form_key` | 处理人从表单变量取值的 key |
| `group_key` | 候选组 key |
| `task_type` | `Major`/`Minor`/`Cc` |
| `perform_type` | `ANY`/`ALL`（会签） |
| `assignment_handler` | 处理人分配器类（点号形式） |
| `candidate_users` / `candidate_groups` | 候选人/候选组 |
| `candidate_handler` | 候选人解析类（点号形式） |
| `field.countersign_type` | 会签类型 `PARALLEL`/`SEQUENTIAL` |
| `field.countersign_completion_condition` | 完成条件，如 `#nrOfCompletedInstances==3` |
| `reminder_time` / `reminder_repeat` | 提醒时间 / 重复提醒 |
| `expire_time` | 过期时间 |
| `auto_execute` | 自动办理标记 |
| `callback` | 任务回调类（点号形式） |
| `ext` | 任意扩展数据（透传） |

### 自定义节点属性

| 属性 | 说明 |
|------|------|
| `clazz` | 外部处理类（点号形式 `madong.workflow.tests.fixture.handler.XXX`） |
| `method_name` | 调用方法名（默认 `handle`） |
| `args` | 参数（支持 `${var}`/`#var`） |
| `var` | 结果写入的流程变量名 |

### 子流程节点属性

| 属性 | 说明 |
|------|------|
| `process_define_id` | 子流程定义 id |
| `version` | 子流程版本号 |

## 三、边与决策表达式 (edges)

```json
{
  "sourceNodeId": "decision",
  "targetNodeId": "manager_approve",
  "properties": { "expr": "#f_day>=3" }
}
```

决策表达式支持 `#变量` 与 `${变量}`：

| 表达式 | 说明 |
|--------|------|
| `#f_day<3` | 变量 `f_day` 小于 3 |
| `#f_amount>=1000` | 变量 `f_amount` 大于等于 1000 |
| `#nrOfCompletedInstances==3` | 会签完成数等于 3 |

## 四、类名引用（点号形式）

json 中 `clazz`/`assignment_handler`/`callback`/拦截器等类引用**使用点号**（PHP/JSON 不允许反斜杠 `\`），引擎读取后自动转为命名空间：

```json
"clazz": "madong.workflow.tests.fixture.handler.AmountCalculateHandler"
```

对应真实类：`madong\workflow\tests\fixture\handler\AmountCalculateHandler`
