# 框架基础

> 📚 阅读顺序 **14/14** · ◀ 上一节 [13-实现指南](13-实现指南.md) · 全系列完 · [目录](README.md)

> 引擎的基础设施：容器、切面、事件、模块、表达式、解析器。

## 一、容器 (Container)

基于 PHP-DI 的依赖注入容器，管理服务与扩展参数。

```php
$engine = new Engine(new EngineConfig(
    services:    [IProcessDefineService::class => ProcessDefineService::class],
    extensions:  ['timeout' => 3600],
));
```

通过 `$engine->getContainer()` 访问，支持 `get()`/`set()`/`has()`。

## 二、AOP 切面 (Aspect)

横切逻辑织入，按 `JoinPoint` 触发。

```php
use madong\workflow\aop\{Aspect, JoinPoint, AdviceType, AspectContext};

class AuditAspect implements Aspect
{
    public function pointcut(): JoinPoint { return JoinPoint::TASK_CREATE; }
    public function adviceType(): AdviceType { return AdviceType::AROUND; }
    public function priority(): int { return 0; }
    public function name(): string { return 'audit'; }

    public function invoke(AspectContext $ctx, ?callable $proceed = null): void
    {
        if ($proceed) $proceed();
    }
}
```

全部 `JoinPoint`：`PROCESS_START`、`PROCESS_END`、`NODE_PRE_EXECUTE`、`NODE_POST_EXECUTE`、`NODE_AROUND_EXECUTE`、`TASK_CREATE`、`TASK_COMPLETE`、`TASK_ASSIGN`、`TRANSITION_EXECUTE`、`ERROR_HANDLER`。

## 三、事件 (EventBus)

发布/订阅流程生命周期事件。

```php
use madong\workflow\event\{ProcessEvent, ProcessEventListener};
use madong\workflow\enum\EventType;

class NotificationListener implements ProcessEventListener
{
    public function onEvent(ProcessEvent $event): void
    {
        // $event->eventType / $event->sourceId / $event->data
    }
}

$engine->getEventBus()->subscribe(EventType::TASK_START->value, new NotificationListener());
```

事件类型：`process.start`、`process.end`、`task.start`、`task.complete`、`task.assign`、`node.enter`、`node.leave`。

## 四、模块 (Module)

带生命周期的插拔式扩展，依赖自动拓扑排序。

```php
use madong\workflow\modular\Module;
use madong\workflow\container\Container;

class NotifyModule implements Module
{
    public function id(): string { return 'notify'; }
    public function depends(): array { return ['core']; }
    public function register(Container $container): void {}
    public function boot(): void {}
    public function shutdown(): void {}
}
```

内置模块：`CoreModule`、`ParserModule`、`EventModule`、`InterceptorModule`。

## 五、表达式引擎 (ExpressionEngine)

决策表达式求值，支持 `#变量` / `${变量}`。

```php
$engine->getExpressionEngine()->evaluateToBool('#f_day<3', $variables);
```

## 六、解析器

### 节点解析器 (NodeParserRegistry)

注册/管理 8 种节点解析器：

```php
$registry = $engine->getParserRegistry();
```

### 设计器解析器 (DesignerParserRegistry)

解析第三方设计器 json：

```php
$engine->getDesignerRegistry()->register(new MyDesignerParser());
```

默认内置 LogicFlow 解析器 `LfDesignerParser`。

## 七、执行上下文 (ExecutionContext)

贯穿节点执行的上下文，携带实例/任务/操作人/变量/引擎。

```php
$ctx->processInstanceId;  // 实例 id
$ctx->operator;           // 操作人
$ctx->getVariable('key'); // 取流程变量
```
